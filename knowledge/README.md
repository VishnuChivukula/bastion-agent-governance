# Knowledge notes for the Assessor and Reviewer agents

Short, paraphrased working notes on four parts of the EU AI Act. They are **not** the legal text and not legal advice. Every statement is a starting point written by an AI assistant and is marked `[VERIFY]`: the repository owner checks each against the primary source (see `docs/VERIFY.md`).

The Assessor and Reviewer agents receive these notes verbatim in their prompt. Editing a note changes the prompts, so the recorded model fixtures must be re-recorded (`make record`).
